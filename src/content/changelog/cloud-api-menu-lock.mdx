title: "Cloud API menu lock"
tags: ["Cloud API", "API"]
publishedDate: 2026-10-28
---

You can now protect Solo menu access in unattended Cloud API setups with a 4-digit passcode. Menu lock is available on Solo readers running firmware 3.3.44.0 or higher.

New reader settings endpoints let you:

- Enable or disable menu lock on a paired Solo reader
- Set or update the 4-digit passcode
- Retrieve the current menu lock configuration for a reader

Use `PATCH /v0.1/merchants/{merchant_code}/readers/{reader_id}/settings` to update settings and `GET` on the same path to consult them. The reader must be online for updates to apply.

See the [Cloud API guide](/terminal-payments/cloud-api/#reader-settings-menu-lock) for request examples and integration notes.
