[iOS SDK](https://github.com/sumup/sumup-ios-sdk) 7.3.0 has been [released](https://github.com/sumup/sumup-ios-sdk/releases/tag/v7.3.0).

**Added:**

- Support for access token providers.

**Improved:**

- Faster Tap to Pay transactions.

**Fixed:**

- An issue that could cause crashes when using Solo and Solo Lite readers.
