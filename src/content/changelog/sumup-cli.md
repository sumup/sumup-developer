We are happy to announce the release of the [SumUp CLI](https://github.com/sumup/sumup-cli), a command-line tool for interacting with SumUp APIs directly from your terminal.

Use the CLI to explore API operations, manage your SumUp account, create online checkouts, control paired readers, and automate workflows with JSON output. It also supports saved merchant context, shell completion, and generated man pages.

Install it with Homebrew:

```bash
brew install sumup/cli/sumup
```

See the [SumUp CLI guide](/tools/cli/) for installation, authentication, and usage instructions, or review the [v0.5.0 release](https://github.com/sumup/sumup-cli/releases/tag/v0.5.0) on GitHub.
