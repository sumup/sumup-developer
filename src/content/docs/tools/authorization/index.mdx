SumUp provides a REST API to manage checkouts, retrieve transactions, and perform other operations programmatically. Authorize your application before making requests. For card-present integrations, you also need to provide an [Affiliate Key](/tools/authorization/affiliate-keys/).​

Key topics in this section:

- **[Authorization](/tools/authorization/authorization/)** – explains how to use API Keys or OAuth 2.0 access tokens.
- **[Affiliate Keys](/tools/authorization/affiliate-keys/)** – learn why affiliate
  keys are required and how to generate one.

Once you are familiar with these concepts, you can explore the detailed
[API reference](/api/).
