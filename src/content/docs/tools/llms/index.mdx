Use your AI assistant to build SumUp payment integrations, troubleshoot checkout flows, or query your merchant account. SumUp provides integration guidance through Agent Skills and API access through the Model Context Protocol (MCP).

## Get Started

[Set up your AI assistant](/tools/llms/setup/) for client-specific installation, authentication, and verification instructions. The guide covers Codex, Claude Code, Cursor, Gemini CLI, Kiro, VS Code, and Claude Desktop.

After setup, try prompts such as:

- "Help me choose between SumUp Hosted Checkout and the Payment Widget."
- "Implement a SumUp Payment Widget checkout with server-side checkout creation."
- "Use the SumUp MCP tools to show my merchant profile."

Skills provide integration guidance without requiring credentials. Account queries require an authenticated MCP connection.

## Explore the Tools

| Tool | Use it for |
| --- | --- |
| [Agent Skills](/tools/llms/agent-skills/) | Focused guidance for implementing, testing, upgrading, and debugging integrations; browse the skill catalog or install skills on their own. |
| [MCP Server](/tools/llms/mcp-server/) | SumUp API tools and documentation resources; learn about authentication, local setup, and troubleshooting. |
| [Agent Toolkit](/tools/llms/agent-toolkit/) | SumUp API tools for your own applications built with LangChain, AI SDK, the OpenAI Agents SDK, or MCP. |

## Plain Text Docs

AI tools can discover our documentation through [/llms.txt](/llms.txt). To read a page as Markdown, append `index.md` to its URL, for example [this overview as Markdown](/tools/llms/index.md).

Markdown versions include content from every tab and preserve heading structure, making them useful for assistants and agents. For hosted skill discovery, see [Discover Skills](/tools/llms/agent-skills/#discover-skills).
