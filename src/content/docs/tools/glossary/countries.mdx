A SumUp merchant account has a default currency based on the country where the
merchant is registered. Product availability varies by country. Check your
integration guide for the countries and currencies it supports.

## Use the correct currency in an integration

Read `default_currency` from the [Retrieve a Merchant endpoint](/api/merchants/get/)
and use that code in payment requests that require a currency, such as
[Create a Checkout](/api/checkouts/create/).

For online payments, use the [payment methods](/online-payments/payment-methods/)
available for the checkout.
