Use your merchant account's default currency when a payment request asks for a currency code. Find the default by [country of registration](/tools/glossary/countries/) or read `default_currency` from the [Retrieve a Merchant endpoint](/api/merchants/get/). Currency availability depends on your integration and the country where your merchant account is registered.

## Minor units

A minor-unit amount is an integer that counts the smallest units SumUp uses for a currency.

- **Two decimal places.** Multiply the amount by 100. For example, EUR 10.10 is `1010` in minor units.
- **Zero decimal places.** Use the whole amount as-is. For example, COP 4251 is `4251` in minor units.

### Special cases

[ISO 4217](https://www.iso.org/iso-4217-currency-codes.html) standard defines two decimal places for `COP` and `HUF`. For these currencies SumUp uses zero decimal places.
