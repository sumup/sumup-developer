Use the Android reader SDK for Bluetooth card readers. Tap to Pay on Android uses a separate SDK with its own dependencies and authentication.

Start with the [quickstart](/terminal-payments/sdks/android/quickstart/) to take your first sandbox payment with a card reader.

## At a glance

|                         |                                                                      |
| ----------------------- | -------------------------------------------------------------------- |
| Languages               | Kotlin and Java                                                      |
| Reader SDK distribution | Maven (`com.sumup:merchant-sdk`)                                     |
| Source and samples      | [Android SDK repository](https://github.com/sumup/sumup-android-sdk) |

## Sample app

SumUp provides a sample app which implements main SDK components. You can find the app under [App directory](https://github.com/sumup/sumup-android-sdk/tree/master/app) of the repository.
