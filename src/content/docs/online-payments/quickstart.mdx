Take a sandbox payment on a SumUp-hosted payment page. Your script creates the checkout, SumUp collects payment details, and you verify the result from your server or a trusted development terminal.

## Prerequisites

- A [sandbox merchant account](/online-payments/#getting-a-sandbox-merchant-account) with EUR as its currency for this example.
- A secret [API key](/tools/authorization/api-keys/) created in that sandbox merchant and its merchant code.
- The runtime and package manager for your chosen language, listed in step 2.

Use the sandbox merchant's credentials throughout these steps. Selecting the sandbox in the Dashboard alone does not change the merchant used by your API key. Keep secret credentials on your server or development machine.

## 1. Configure your credentials

Create a directory for this example, then set these variables in your terminal, replacing the placeholders:

```bash
mkdir sumup-quickstart
cd sumup-quickstart

export SUMUP_API_KEY="YOUR_SANDBOX_SECRET_API_KEY"
export SUMUP_MERCHANT_CODE="YOUR_SANDBOX_MERCHANT_CODE"
```

## 2. Create a Hosted Checkout

Choose your language below. Each program creates a checkout when run without arguments. In step 4, you will pass its ID to the same program to retrieve the payment status.

<Tabs syncKey="backend_lang">

  <TabItem label="JavaScript" icon="seti:javascript">
    Use Node.js 24 or later and npm.

    Install the SDK in your example directory:

    ```bash
    npm install @sumup/sdk@0.2.2
    ```

    Save this program as `checkout.mjs`:

    ```js
    import { randomUUID } from "node:crypto";
    import SumUp from "@sumup/sdk";

    const client = new SumUp({ apiKey: process.env.SUMUP_API_KEY });
    const checkoutId = process.argv[2];

    if (checkoutId) {
      const checkout = await client.checkouts.get(checkoutId);
      console.log("Status:", checkout.status);
    } else {
      const checkout = await client.checkouts.create({
        checkout_reference: randomUUID(),
        amount: 10,
        currency: "EUR",
        merchant_code: process.env.SUMUP_MERCHANT_CODE,
        hosted_checkout: { enabled: true },
      });
      console.log("Checkout ID:", checkout.id);
      console.log("Payment page:", checkout.hosted_checkout_url);
    }
    ```

    Run it to create a checkout:

    ```bash
    node checkout.mjs
    ```

  </TabItem>

  <TabItem label=".NET" icon="seti:c-sharp">
    Use .NET SDK 8 or later.

    Install the SDK in your example directory:

    ```bash
    dotnet new console --name SumUpQuickstart --output .
    dotnet add package SumUp --version 0.0.21
    ```

    Save this program as `Program.cs` (replace the generated file):

    ```csharp
    using SumUp;

    using var client = new SumUpClient(new SumUpClientOptions
    {
        AccessToken = Environment.GetEnvironmentVariable("SUMUP_API_KEY"),
    });

    if (args.Length > 0)
    {
        var response = await client.Checkouts.GetAsync(args[0]);
        var checkout = response.Data
            ?? throw new InvalidOperationException("Checkout not returned");
        Console.WriteLine($"Status: {checkout.Status?.ToString().ToUpperInvariant()}");
    }
    else
    {
        var response = await client.Checkouts.CreateAsync(new CheckoutCreateRequest
        {
            CheckoutReference = Guid.NewGuid().ToString(),
            Amount = 10.0f,
            Currency = Currency.Eur,
            MerchantCode = Environment.GetEnvironmentVariable("SUMUP_MERCHANT_CODE")!,
            HostedCheckout = new HostedCheckout { Enabled = true },
        });
        var checkout = response.Data
            ?? throw new InvalidOperationException("Checkout not returned");
        Console.WriteLine($"Checkout ID: {checkout.Id}");
        Console.WriteLine($"Payment page: {checkout.HostedCheckoutUrl}");
    }
    ```

    Run it to create a checkout:

    ```bash
    dotnet run
    ```

  </TabItem>

  <TabItem label="Java" icon="seti:java">
    Use Java 17 or later and Gradle.

    Save this as `build.gradle`:

    ```groovy
    plugins { id 'application' }
    repositories { mavenCentral() }
    dependencies { implementation 'com.sumup:sumup-sdk:0.1.2' }
    application { mainClass = 'Checkout' }
    ```

    Create the source directory:

    ```bash
    mkdir -p src/main/java
    ```

    Save this program as `src/main/java/Checkout.java`. The JSON configuration maps Java field names to the API's snake-case names for SDK 0.1.2:

    ```java
    import com.fasterxml.jackson.annotation.JsonInclude;
    import com.fasterxml.jackson.databind.DeserializationFeature;
    import com.fasterxml.jackson.databind.PropertyNamingStrategies;
    import com.fasterxml.jackson.databind.json.JsonMapper;
    import com.sumup.sdk.core.ApiClient;
    import com.sumup.sdk.SumUpClient;
    import com.sumup.sdk.models.CheckoutCreateRequest;
    import com.sumup.sdk.models.Currency;
    import com.sumup.sdk.models.HostedCheckout;
    import java.util.UUID;

    public class Checkout {
        public static void main(String[] args) throws Exception {
            var mapper = JsonMapper.builder()
                .findAndAddModules()
                .propertyNamingStrategy(PropertyNamingStrategies.SNAKE_CASE)
                .disable(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES)
                .build();
            mapper.setDefaultPropertyInclusion(JsonInclude.Include.NON_NULL);
            var client = SumUpClient.builder().apiClient(
                ApiClient.builder()
                    .accessToken(System.getenv("SUMUP_API_KEY"))
                    .objectMapper(mapper)
                    .build()
            ).build();

            if (args.length > 0) {
                var checkout = client.checkouts().get(args[0]);
                System.out.println("Status: " + checkout.status());
            } else {
                var checkout = client.checkouts().create(
                    CheckoutCreateRequest.builder()
                        .checkoutReference(UUID.randomUUID().toString())
                        .amount(10.0f)
                        .currency(Currency.EUR)
                        .merchantCode(System.getenv("SUMUP_MERCHANT_CODE"))
                        .hostedCheckout(HostedCheckout.builder().enabled(true).build())
                        .build()
                );
                System.out.println("Checkout ID: " + checkout.id());
                System.out.println("Payment page: " + checkout.hostedCheckoutUrl());
            }
        }
    }
    ```

    Run it to create a checkout:

    ```bash
    gradle run
    ```

  <TabItem label="Go" icon="seti:go">
    Use Go 1.25 or later.

    Install the SDK in your example directory:

    ```bash
    go mod init example.com/sumup-quickstart
    go get github.com/sumup/sumup-go@v0.21.0
    ```

    Save this program as `main.go`:

    ```go
    package main

    import (
        "context"
        "crypto/rand"
        "fmt"
        "os"

        sumup "github.com/sumup/sumup-go"
    )

    func main() {
        if err := run(); err != nil {
            fmt.Fprintln(os.Stderr, err)
            os.Exit(1)
        }
    }

    func run() error {
        client := sumup.NewClient()
        ctx := context.Background()

        if len(os.Args) > 1 {
            checkout, err := client.Checkouts.Get(ctx, os.Args[1])
            if err != nil {
                return fmt.Errorf("get checkout: %w", err)
            }
            if checkout.Status == nil {
                return fmt.Errorf("checkout status missing")
            }
            fmt.Println("Status:", *checkout.Status)
            return nil
        }

        checkout, err := client.Checkouts.Create(ctx, sumup.CheckoutsCreateParams{
            CheckoutReference: rand.Text(),
            Amount:            10,
            Currency:          sumup.CurrencyEUR,
            MerchantCode:      os.Getenv("SUMUP_MERCHANT_CODE"),
            HostedCheckout:    &sumup.HostedCheckout{Enabled: true},
        })
        if err != nil {
            return fmt.Errorf("create checkout: %w", err)
        }
        if checkout.ID == nil || checkout.HostedCheckoutURL == nil {
            return fmt.Errorf("checkout ID or payment page missing")
        }
        fmt.Println("Checkout ID:", *checkout.ID)
        fmt.Println("Payment page:", *checkout.HostedCheckoutURL)
        return nil
    }
    ```

    Run it to create a checkout:

    ```bash
    go run main.go
    ```

  <TabItem label="Rust" icon="seti:rust">
    Use Rust 1.90 or later and Cargo.

    Install the SDK in your example directory:

    ```bash
    cargo init --name sumup-quickstart
    cargo add sumup@0.6.0 serde_json@1
    cargo add tokio@1 --features macros,rt-multi-thread
    cargo add uuid@1 --features v4
    ```

    Save this program as `src/main.rs` (replace the generated file):

    ```rust
    use sumup::{checkouts, Client, Currency};
    use uuid::Uuid;

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let client = Client::default();

        if let Some(checkout_id) = std::env::args().nth(1) {
            let checkout = client.checkouts().get(checkout_id).await?;
            let status = serde_json::to_value(checkout.status)?;
            println!("Status: {}", status.as_str().unwrap_or("UNKNOWN"));
        } else {
            let checkout = client.checkouts().create(
                checkouts::CreateRequest::builder()
                    .checkout_reference(Uuid::new_v4().to_string())
                    .amount(10.0)
                    .currency(Currency::EUR)
                    .merchant_code(std::env::var("SUMUP_MERCHANT_CODE")?)
                    .hosted_checkout(checkouts::HostedCheckout { enabled: true })
                    .build(),
            ).await?;
            println!("Checkout ID: {}", checkout.id.ok_or("Checkout ID missing")?);
            println!("Payment page: {}", checkout.hosted_checkout_url.ok_or("Payment page missing")?);
        }
        Ok(())
    }
    ```

    Run it to create a checkout:

    ```bash
    cargo run
    ```

The program prints a new checkout ID and its payment-page URL. Save both. Creating a checkout does not charge the customer.

## 3. Complete the sandbox payment

Open the returned payment-page URL in your browser and choose card payment. Use this [sandbox test card](/online-payments/testing/#test-successful-payments):

| Field           | Value                 |
| --------------- | --------------------- |
| Card number     | `4200 0000 0000 0091` |
| Expiry          | Any future date       |
| CVV             | `123`                 |
| Cardholder name | Any name              |

Submit the payment and follow any authentication instructions. The sandbox simulates the payment without moving real funds.

## 4. Verify the result


## You should see

The payment page shows success, and your program prints:

```text
Status: PAID
```

If the status is still `PENDING`, finish the browser payment and retrieve the same checkout again. If it is `FAILED` or `EXPIRED`, use the [testing guide](/online-payments/testing/) to diagnose the result. A success page or browser redirect alone is not your backend's payment confirmation.
