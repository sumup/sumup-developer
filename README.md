The site is built with [Astro](https://astro.build/) and the [Starlight](https://starlight.astro.build/) documentation theme. Documentation pages are written in Markdown and MDX.

## Local Development

### Prerequisites

- Node.js 24.x, as specified in `.nvmrc` and `package.json`
- npm 11.x

Using a Node version manager such as [nvm](https://github.com/nvm-sh/nvm) makes it easier to use the version required by the repository.

### Set up the Project

Clone the repository:

```bash
git clone git@github.com:sumup/sumup-developer.git
cd sumup-developer
```

If you use nvm, install and select the configured Node.js version:

```bash
nvm install
nvm use
```

Install the locked dependencies:

```bash
npm ci
```

No environment variables are required to install, build, or browse the documentation locally. Deployment-only integrations, including analytics and contact-form delivery, require secrets that are not stored in the repository.

### Start the Development Server

```bash
npm run dev
```

Open `http://localhost:3000` in a browser. Most content and component changes appear without restarting the server.

## Validate Changes

Run the checks that match your change before opening a pull request:

| Command             | Purpose                                         |
| ------------------- | ----------------------------------------------- |
| `npm run check`     | Validate Astro, TypeScript, and content schemas |
| `npm run lint`      | Lint source files and Markdown                  |
| `npm run test`      | Run the Vitest test suite                       |
| `npm run build`     | Create the production Cloudflare build          |
| `npm run linkcheck` | Build the site and validate internal links      |

## Cloudflare Previews

Cloudflare Workers Builds deploys `main` to production and uses Worker Previews for other branches. Preview URLs are available in Cloudflare and posted to pull requests after a successful build.

To deploy a preview from a local branch with Cloudflare credentials:

```bash
npm run build
npx wrangler preview
```

The `previews` block in `wrangler.jsonc` enables the preview configuration. The Astro adapter adds the asset and session bindings. Preview build variables are configured separately from production in Cloudflare, including the Marketing Cloud settings used by the contact form. Configure test credentials and endpoints there when testing form submissions.

Branches created before the preview migration should rebase onto the updated `main` to pick up the Wrangler upgrade and preview configuration.

## API Specs

The OpenAPI definition used by the [API Reference](https://developer.sumup.com/api/) is managed in another repository and synchronized into `openapi.yaml`. Do not edit this file directly. If you find a mistake or have an improvement to suggest, [open an issue](https://github.com/sumup/sumup-developer/issues/new).
